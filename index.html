Introduction

RealClawBench is a live benchmark framework for developer-facing agents. It starts from real OpenClaw user sessions rather than manually authored prompts, then reconstructs workspaces, rewrites requests into standalone instructions, and scores model runs with deterministic verifiers.

The first frozen release contains 281 executable tasks sampled from a much larger deployed-session pool while preserving the source distribution. Across 14 contemporary models, the strongest system solves only 65.8% of tasks, leaving substantial headroom on realistic developer-agent workloads.

Session-to-task construction

From real OpenClaw sessions to reproducible benchmark releases

RealClawBench begins from real developer-agent sessions and applies privacy screening, environment reconstruction, intent-preserving rewrite, rule-based verifier construction, and frozen release packaging. This lets later OpenClaw windows become live benchmark versions without changing the historical main leaderboard.

Real-demand task mix

281 tasks across file creation, code fixing, data querying, commands, and project building

The benchmark is not manually balanced. Frequent real workflows shape the sample-average score, while task and subtask macro-averages reveal whether a model remains robust on smaller, long-tail task families.

Model capability and efficiency

Accuracy and cost are not the same story

The main leaderboard shows substantial headroom: the best model reaches 65.8% sample-average pass rate. The cost-accuracy view further shows that higher spending does not automatically translate into higher verifier success, motivating joint reporting of accuracy, robustness, and operational efficiency.

Deterministic Scoring

Leaderboard rankings are computed only from case-specific deterministic verifiers. LLM auditing is reserved for scorer analysis, not model ranking.

Versioned Live Benchmarking

The main release stays frozen for controlled comparison, while later windows are published separately to track temporal demand shift.
